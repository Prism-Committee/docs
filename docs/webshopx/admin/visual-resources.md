# 视觉资源包

视觉资源包为网页提供 Minecraft 物品图标和多语言名称。它只影响展示，不改变物品 ID、Data Components、交易匹配或实际库存。

## 1. 管理入口

以管理员身份进入“系统设置 → 视觉资源”。旧入口 `/admin/visual-packs` 会跳转到该设置页。

管理员可以上传、启用或停用视觉包，并调整多个包的先后顺序。列表越靠前的包越优先；最终显示还会受到全局“解析优先级”影响。

## 2. 解析优先级

当前可配置的展示来源包括管理员材质对照表、官方商城商品自定义、玩家市场挂单自定义、视觉资源包、WebShopX 内置资源、英文名称和物品 ID 回退。

图标与名称可以采用不同的解析顺序。修改后应分别检查原版物品、自定义模型物品和缺少当前语言翻译的物品。

## 3. 上传前检查

- 文件来自可信来源，且是 WebShopX 支持的视觉包 ZIP。
- 包内包含清单、图标目录和所需语言文件。
- 不要解压后重新压缩出额外的顶层目录。
- 同一物品在多个包中重复时，先确定期望的优先级。
- 上传后验证图标、当前语言名称和回退名称。

## 4. WebShopX Icon Exporter（尚未发布）

:::caution[未发布预览]

WebShopX Icon Exporter 尚未正式发布。以下内容用于提前说明预期流程，不代表已经存在可下载的稳定版本。

:::

该工具计划作为 NeoForge 客户端 Mod，使用 Minecraft 当前加载的 GUI 物品渲染与资源包生成 WebShopX 视觉包。当前开发基线为 Minecraft `1.21.10`、NeoForge `21.10.64` 和 Java `21`。

预期流程：

1. 将未来发布的 Mod 放入客户端整合包的 `mods`。
2. 启用需要导出的资源包并进入世界。
3. 执行 `/webshopx-icons export`。
4. 在导出界面查看进度；需要时按 `Esc` 取消。
5. 从 `<游戏目录>/webshopx-icon-packs/` 获取 ZIP，再上传到 WebShopX。

预期配置文件为 `<游戏目录>/config/webshopx-icon-exporter.json`，可设置输出尺寸和导出语言。首版计划导出每个注册物品的默认 `ItemStack`；药水、染色、旗帜、地图和其他多状态物品不会自动穷举全部变体。

正式发布前，请不要寻找或传播非官方构建。
