# 运维与故障处理

本页把 WebShopX 日常运维中最常见的“东西没到、订单卡住、升级前后、库存异常、集群不同步”等问题集中在一起，避免为每一种故障单独跳转页面。

## 1. 订单与发货状态

常见订单状态：

- `PENDING`：等待处理；
- `WAIT_CLAIM`：自动发货未完成，需要玩家手动领取；
- `DELIVERED`：已完成发货；
- `REFUNDED`：已退款；
- `CANCELLED`：订单已取消。

自动发货连续失败后会回退到 `WAIT_CLAIM`。排查时先看订单状态，再看玩家是否在线、背包是否有空间，以及对应错误日志。

## 2. Claim 与 Mailbox

玩家常用：

```text
/ws claim [all|ODR-|MKT-|CLM-|MCL-]
/ws mailbox
/ws mailbox collect
```

建议排障顺序：

1. 先确认订单是否仍处于 `WAIT_CLAIM`；
2. 尝试 `/ws claim all`；
3. 检查玩家背包空间；
4. 检查 mailbox 是否已有待领取物品；
5. 最后再核查日志和订单记录。

不要连续重复执行同一个写操作来“碰运气”，尤其是在网络或数据库状态不稳定时。

## 3. 退款

退款是否允许取决于订单状态和当前服务器策略。

常见情况：

- 已成功交付的订单通常不能按“未发货退款”处理；
- `PENDING` / `WAIT_CLAIM` 是否可退取决于当前策略；
- 超过退款窗口可能返回 `refund_expired`；
- 已退款订单会返回 `already_refunded` 或等价状态。

管理员处理争议时，应同时核对订单、钱包流水、审计日志和实际交付状态，不要只根据玩家截图判断。

## 4. 网页背包与库存安全

### 在线玩家

在线操作应以服务器内实时库存为准。

### 离线玩家

离线展示可能来自只读快照；快照用于展示，不代表物品仍然存在，也不能作为人工补发的唯一依据。

离线直接写入 `playerdata` 属于实验性能力。启用前至少确认：

- 单实例或明确支持的部署；
- 没有其它插件同时修改同一玩家库存；
- 已完成世界和玩家数据备份；
- 已在测试服验证；
- 能处理玩家登录与 Web 写入之间的竞态。

出现复制、丢失或数据损坏风险时，应立即关闭相关能力并保留日志、备份和复现步骤。

## 5. 备份与升级

升级前建议至少备份：

- 数据库或 SQLite 文件；
- `plugins/WebShopX/`；
- 涉及实验性离线库存写入时的玩家数据。

推荐升级流程：

1. 备份；
2. 停服；
3. 替换插件 jar；
4. 启动并观察启动日志；
5. 验证登录、钱包、下单、市场、领取和后台；
6. 集群环境继续验证节点同步和 Redis；
7. 确认无异常后再恢复正常运营。

## 6. Relay 与集群

### Relay

遇到“网页打不开但服务器正常”时，依次确认：

1. 当前是否为 `relay` 模式；
2. Relay 授权/访问密钥是否仍有效；
3. `/ws home` 返回的地址是否正确；
4. 网络出口、防火墙和 DNS 是否正常。

### 集群

集群问题优先检查：

- 所有节点 WebShopX 版本是否一致；
- `cluster.role` 和 `server-id` 是否正确；
- Redis 是否可达；
- channel 配置是否一致；
- runtime config 更新是否能被其它节点接收。

SQLite 只适合 `standalone`，不要用于 `master/node` 集群角色。

## 7. 权限、后台与审计

遇到“按钮有但操作失败”或后台 `forbidden` 时：

1. 确认当前管理员角色；
2. 检查对应 `AdminPermission`；
3. 确认账号仍处于启用状态；
4. 查看审计日志中是否存在被拒绝或刚刚执行的同类操作。

不要为了快速解决问题直接把所有管理员都设为 Super Admin。

## 8. 提交问题时提供什么

为了让问题能快速复现，请提供：

- WebShopX 版本；
- Minecraft / Paper / Purpur / Spigot / Folia 版本；
- Java 版本；
- 单服还是集群；
- 数据库类型；
- 可复现步骤；
- 相关错误码和日志片段；
- 是否安装 Vault、WebShopX-Payments 或其他库存/经济插件。

问题反馈仓库：[Prism-Committee/WebShopX-Issues](https://github.com/Prism-Committee/WebShopX-Issues)
