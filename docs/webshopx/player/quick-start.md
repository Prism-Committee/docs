# 快速上手

本页只解决一件事：**从游戏内完成账号准备，并成功登录 WebShopX 网页。**

## 1. 设置网页密码

在游戏内执行：

```text
/ws password <你的新密码>
```

密码应使用 8 到 64 个字符。设置或重置密码后，旧会话可能失效，需要重新登录。

## 2. 获取网页地址

执行：

```text
/ws home
```

服务器会返回服主配置的 WebShopX 地址。若没有可用地址，请联系服务器管理员。

## 3. 登录

打开网页后，使用你的 Minecraft 玩家名（或服务器允许的玩家标识）和刚刚设置的密码登录。

:::tip
正常玩家不需要自行“注册一个新的 WebShopX 用户名”。账号身份来自服务器中的玩家资料，`/ws password` 用于设置或重置网页登录密码。
:::

## 常见问题

### `invalid_password`

密码格式或长度不符合要求。请重新设置 8 到 64 位密码。

### `invalid_credentials`

登录凭证不正确。确认玩家名和密码后重试；必要时在游戏内重新执行 `/ws password`。

### `auth_invalid`

当前会话已经失效或过期。退出网页账号后重新登录。

### `/ws home` 没有给出可用网址

这通常是服务器端的 WebShopX 公网地址或部署模式尚未配置完成，请联系服务器管理员。
