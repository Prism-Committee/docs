# 玩家入口

这个页面保留用于兼容旧链接。新的 WebShopX 文档不再把所有玩家功能拆成大量平级页面，而是按实际任务组织在 [Guides](../guides/overview) 中。

## 第一次使用

先阅读 [快速开始](./quick-start)：

```text
/ws password <新密码>
/ws home
```

完成登录后，再按需要进入：

- [商城、市场与订单](./shop-and-orders)
- [钱包与兑换](./wallet-and-exchange)
- [背包、领取与信箱](../guides/inventory-and-delivery)
- [拍卖、动态定价与交易规则](../guides/auctions-and-pricing)
- [常见问题](./faq)

原有的拍卖、动态价格、算法、上架限制等专题页仍保留为深读资料，但不再占据主导航。
