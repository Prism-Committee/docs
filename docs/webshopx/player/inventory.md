# 网页背包与快捷交易
> 这是内测功能，正式版可能暂未接入此功能，请以实际为准。你也可以加入QQ群进行后续新功能内测。
网页的“背包”页面可以查看真实背包和末影箱，并直接从物品槽位直接发起交易。

## 1. 现状

玩家在线时可以安全进行背包管理，玩家离线时背包管理为实验性功能，可能暂未稳定，默认关闭，可由管理员开启。

`我的背包` 页面会显示当前登录玩家的背包，以及物品名称、数量、附魔、Lore、装备位置等。支持直接从背包上架到玩家市场（包含求购和售卖）、拍卖行等。

## 2. 可用操作

- **满足收购**：选择与物品完整匹配的官方或玩家收购挂单，确认预计收入、手续费和实际到账。
- **固定价上架**：设置数量、单价、币种和展示信息。
- **发起拍卖**：设置起拍价、持续时间等拍卖参数。

提交前服务器会再次校验真实槽位和物品内容。若物品已移动、数量改变或不再满足限制，请刷新页面后重试。

## 3. 在线与离线状态

| 状态 | 含义 | 可否交易 |
| --- | --- | --- |
| 玩家在线 | 读取服务器中的实时背包或末影箱 | 可以 |
| 离线只读快照 | 显示玩家最后在线时保存的内容 | 不可以 |
| 服务器持久化背包 | 服主已显式开启实验性的离线即时管理 | 可以，但有一定风险 |
| 尚无快照 | 玩家从未在支持快照的版本中上线 | 不可以 |

离线只读快照仅用于查看，不能视为可写库存。快照保留时间由服主设置，玩家重新上线后会刷新。

:::warning[离线即时管理/持久化背包]

介绍：该功能默认关闭。该功能目前仅支持单服模式，若服务器需跨服同步背包、多服部署等，请谨慎开启。

风险来源：该功能会直接修改服务器保存的玩家数据，当服务器修改玩家数据文件时，如果服务端也同步修改（如在同时或几乎同时玩家上线，或服务器关闭可能会造成数据损坏），尽管它发生的可能性极小但依旧无法避免。WebShopX已经尽可能把风险控制在最小范围：WebShopX不会直接写入、只会在临时备份写入并在替换时进行数据锁。
:::

## 4. 常见问题

### 页面显示的物品和游戏内不一致

先确认页面顶部显示的是实时库存还是离线快照，再点击“刷新”。离线只读快照不会跟随离线期间的外部数据变更实时更新。

### 按钮不可用

常见原因包括：玩家离线且只有只读快照、物品被服务器规则禁止交易、没有匹配的收购单、没有自定义展示权限，或服务器已关闭对应能力。
