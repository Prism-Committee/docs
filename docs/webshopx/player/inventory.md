# 网页背包与快捷交易

:::caution[功能状态：测试 / 实验性]
网页背包能力会随服务器版本和管理员设置而变化。在线背包操作与离线背包能力并不等价；是否开放离线写入由服务器管理员决定。
:::

网页的“背包”页面用于查看当前玩家的背包或末影箱，并在服务器允许时直接从物品槽位发起市场操作。

## 可以做什么

根据服务器启用的功能，你可能可以：

- 查看物品名称、数量、附魔、Lore 和装备位置；
- 将物品按固定价上架到玩家市场；
- 使用物品满足匹配的收购单；
- 发起拍卖。

提交交易前，服务器会再次核对真实槽位和物品内容。如果物品已经移动、数量改变或不再满足交易限制，请刷新页面后重试。

## 在线与离线的区别

| 页面状态 | 你看到的内容 | 是否可直接交易 |
| --- | --- | --- |
| 在线实时背包 | 当前服务器中的实时库存 | 通常可以 |
| 离线只读内容 | 玩家离线前保存的可查看内容 | 不可以 |
| 离线可管理库存 | 服务器管理员显式开放的实验性能力 | 取决于服务器配置 |
| 暂无可用数据 | 尚未取得可展示的库存信息 | 不可以 |

:::warning
离线状态下看到的内容不一定代表当前磁盘中的最终玩家数据，也不能默认视为可写库存。请以页面显示的状态和按钮是否可用为准。
:::

## 常见问题

### 页面显示的物品和游戏内不一致

先确认页面显示的是“在线实时”还是“离线只读”，然后刷新页面。离线数据不会在玩家离线期间持续同步所有外部变化。

### 按钮不可用

常见原因包括：

- 当前只有离线只读数据；
- 物品被服务器规则禁止交易；
- 没有匹配的收购单；
- 当前账号没有对应权限；
- 服务器管理员没有开放该能力。

涉及离线 playerdata 写入、数据锁、回滚和风险控制的内容属于服务器管理员 / 运维范围，不在玩家指南中展开。
