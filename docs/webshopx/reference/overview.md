## 事实源优先级

遇到文档与实际版本不一致时，按下面顺序判断：

1. 你正在运行的 WebShopX 版本代码 / 配置模板；
2. 本 Reference 指向的对应文档；
3. 玩家/管理员教程；
4. README、旧截图或第三方教程。

发现不一致时欢迎在 Prism-Committee 的 Issue 渠道反馈，并注明 WebShopX 版本和相关页面。
