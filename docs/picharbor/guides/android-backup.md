# 备份 Android 照片到电脑

除了通过 USB 连接，PicHarbor 桌面端还支持通过家庭局域网无线拉取 Android 手机上的新增照片与视频。无需翻找数据线，在沙发上就能轻松完成归档。

---

## 准备工作

* **网络要求**：确保你的电脑与 Android 手机连接在**同一个局域网（通常是同一个家用 Wi-Fi 路由器）**下。
* **手机开启 FTP 服务**：
  - 许多国产 Android 手机系统自带的文件管理（如小米“远程管理”、华为“局域网共享”等）均支持一键开启 FTP；
  - 也可以安装常见的文件管理应用（如 Solid Explorer、CX 文件浏览器或 MT 管理器），点击开启“通过 FTP 共享”。

---

## 操作流程

1. **获取连接信息**：
   - 手机端开启 FTP 后，屏幕上会显示类似如下的访问地址：
     > `ftp://192.168.1.108:2121`
2. **在电脑端填写连接**：
   - 打开 PicHarbor 桌面端，在左侧点击“设备备份 -> Android (FTP)”；
   - 填入 IP 地址（`192.168.1.108`）与端口号（`2121`）；
   - 如果手机端设置了账号密码则填写，若是匿名模式则勾选“匿名登录”。
3. **设置设备标识 (Device ID)**：
   - 为这台手机起一个易记的标识（例如 `Pixel8-Pro` 或 `Xiaomi-14`）；
   - PicHarbor 会记住这台设备的历史备份进度。
4. **测试并启动同步**：
   - 点击“测试连接”，确认连通后点击“开始增量同步”；
   - 软件会自动扫描手机中的 `DCIM/Camera` 等相册目录，**自动比对已存在的文件，仅拉取全新拍摄的照片**。

---

## 实用建议

* **大体量视频传输建议靠近路由器**：如果备份包含数十个 4K 60fps 视频片段，建议将手机靠近 5GHz Wi-Fi 路由器，或在手机端设置中选择 5GHz 频段以获得 40~70 MB/s 的高速无线拉取体验。
* **增量保护**：如果手机里某张照片改名了但实际内容和拍摄时间未变，PicHarbor 的内容校验机制能智能识别，避免在电脑上产生无意义的重复副本。
