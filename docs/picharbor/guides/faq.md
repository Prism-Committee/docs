# 常见问题解答 (FAQ)

汇总了初学者与日常使用中最高频遇到的问题与处理方法。

---

## 一、 设备连接与识别

### Q1: iPhone 连上电脑后，PicHarbor 显示“未检测到设备”或状态灯为黄色？
1. **排查锁屏状态**：点亮 iPhone 屏幕并解锁。只有在解锁状态下，iOS 才会允许电脑读取相册元数据。
2. **确认是否点击了信任**：手机屏幕上是否弹出了“信任此电脑？”提示？必须点击“信任”并输入锁屏密码。
3. **检查 Apple 驱动服务**：
   - 检查电脑上是否安装了 **Apple Devices (Apple 设备)** 应用或 **iTunes**；
   - 可以在 Windows 任务管理器中查看是否存在名为 `Apple Mobile Device Service` 的后台服务。若无，请前往微软商店安装“Apple Devices”。
4. **更换 USB 接口或数据线**：台式机请尽量插在机箱背面的主板原生 USB 接口，避免使用供电不足的廉价 USB 分线器（HUB）。

---

### Q2: Android 手机开启 FTP 后，电脑提示“连接超时”？
1. **检查是否在同一局域网**：手机是否开启了蜂窝移动网络而未连上家用 Wi-Fi？电脑与手机必须在同一个路由器网段下（例如都是 `192.168.1.x`）。
2. **检查电脑防火墙**：部分 Windows 第三方杀毒软件可能会拦截外部 FTP 入站请求，请在弹窗时允许 PicHarbor 访问专用网络。
3. **检查 IP 与端口输入**：核对手机端显示的 IP 地址和端口（例如是否漏掉了 `:2121` 后面的端口号）。

---

## 二、 备份与传输过程

### Q3: 为什么备份速度比平常用网盘更快？
PicHarbor 走的是硬件级的物理 USB 3.0 / 直连通道，或者本地局域网千兆传输，直接在设备间点对点流式写入，不经过公网服务器中转，因此速度通常在 30~80 MB/s 之间，几分钟就能备份完上千张照片。

### Q4: 备份中途数据线被碰掉了，会损坏照片吗？
**完全不会。** PicHarbor 采用严格的“原子写入”：所有传输中的文件先写为 `.partial` 临时格式，只有传输完毕且大小哈希校验无误后才更名为真实照片。重新插上后点击“继续”，已经备份好的照片会自动跳过，直接断点续传。

---

## 三、 手机端与云同步

### Q5: iOS 免费侧载安装的客户端，7 天后会闪退吗？
**不会。** PicHarbor iOS 客户端内嵌了 SelfRefreshKit 本地自动续签守护：
* 在证书即将到期前，应用在后台会被定期唤醒并进行本地回环刷新；
* 只要平时正常使用手机，证书将自动循环延续，无需每周重新插电脑重装。

### Q6: 为什么我的 Google 相册上传一直卡在“正在连接”？
Google 相册服务在中国大陆地区网络环境下无法直接访问。如果你在相关网络环境：
* 请在 PicHarbor 移动端的“网络与代理设置”中，导入你的标准代理配置或 Clash 订阅链接，开启应用内代理即可畅快上传。
