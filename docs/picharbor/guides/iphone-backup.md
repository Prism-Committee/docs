# 备份 iPhone 照片到电脑

无论你的 iPhone 中有几千张还是十万张照片，使用 PicHarbor 都能获得比 Windows 资源管理器更可靠、更完整的备份体验。

---

## 核心操作步骤

1. **准备与连接**：
   - 使用原装或优质数据线将 iPhone 连接至电脑的 USB / Type-C 接口；
   - 点亮手机屏幕，解锁后在弹窗中选择**“信任此电脑”**并输入密码。
2. **启动与识别**：
   - 打开 PicHarbor 桌面客户端，点击左侧菜单的“设备备份”；
   - 稍等数秒，系统将自动列出当前设备名称（例如 `iPhone 15 Pro`）、iOS 版本以及检测到的相机照片总数。
3. **选择备份选项**：
   - **完全备份（默认）**：扫描所有未入库的新增媒体并执行备份；
   - **日期过滤**：如果你只想备份最近几个月或特定年份的照片，可展开过滤面板选择时间区间。
4. **点击“开始归档”**：
   - 界面进入实时传输监控，你可以清晰看到当前的传输速率与写入文件。

---

## 特殊格式的无损处理

### 1. 实况照片 (Live Photo)
普通复制往往把实况照片拆分成单独的 `.HEIC` 和 `.MOV`，导致动态效果丢失。
* PicHarbor 的**配对引擎**会自动识别这两者的关联标识；
* 静态高质图像与伴生音频视频流会被同时保存在同一归档子目录下；
* 在 PicHarbor 画廊中双击该照片，依然可以随时按压回放带有声音的动态效果。

### 2. 调色与裁剪修图 (.AAE 文件)
如果你在 iPhone 自带相册里裁剪、旋转或调整了滤镜色调，iOS 系统会生成对应的 XML 侧车描述文件（`.AAE`）。
* PicHarbor 会一并将其归档并与原片绑定，确保日后导出时能够还原修图历史。

### 3. ProRAW 与 RAW+JPEG
单反、微单或 iPhone Pro 拍摄的 RAW 格式（`.DNG`）以及系统生成的预览 JPG，会被一并保留与归类，专业摄影师无需担心格式被强行转换或画质受损。

## 常见疑问

* **Q：备份会删除我手机里的照片吗？**
  * **绝不会！** PicHarbor 对手机文件系统的访问在代码层面是严格“只读”的，没有任何针对手机端的删除指令，你的手机原片完全处于安全隔离状态。
* **Q：中途不小心碰掉线了会怎样？**
  * 当前正在传输的那一张照片会被自动丢弃，重新插上后点击“继续”，已备份好的照片会自动跳过，完全支持断点续传。
