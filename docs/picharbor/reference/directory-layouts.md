# 目录布局规范与清单格式

PicHarbor 在物理硬盘上归档照片时支持多种标准化目录布局，并在归档根目录下维护自持的元数据索引。

---

## 支持的目录布局模式

| 模式标识 | 目录结构示例 | 优缺点与适用场景 |
| :--- | :--- | :--- |
| **`year-month` (推荐)** | `2024/2024-05/IMG_0001.HEIC` | **最均衡方案**。年/月层级清晰，单个子文件夹文件数通常在几百到几千张以内，资源管理器打开迅速。 |
| **`month`** | `2024-05/IMG_0001.HEIC` | **扁平按月**。省去外层年份目录，适合查看跨度较近的照片。 |
| **`year`** | `2024/IMG_0001.HEIC` | **按年汇总**。适合年拍摄量较少（每年几十张到数百张）的轻度用户。 |
| **`flat`** | `IMG_0001.HEIC` | **全平铺**。所有文件均置于根目录。不建议在大库（超过 5000 张）使用，会导致系统文件管理器卡顿。 |

---

## 成员盘自持索引目录 (`.picharbor/`)

每个加入 PicHarbor 逻辑图库的成员盘根目录下，均会自动创建隐藏目录 `.picharbor/`：

```text
D:\Photos\
├── .picharbor/
│   ├── library.db          # 磁盘本地 SQLite 索引数据库 (媒体指纹、拍摄时间、EXIF)
│   ├── thumbnails/         # 高速缩略图缓存 (供画廊快速渲染)
│   └── recycle/            # 30 天防丢回收站 (暂存重复或待清理副本)
├── 2024/
└── 2025/
```

### 数据库恢复能力
即使你重装了电脑系统或在另一台全新电脑上打开 PicHarbor：
* 只需在软件中选择“打开已有归档目录”；
* 软件将直接读取 `.picharbor/library.db`，瞬间恢复所有分类与时间线，无需重新扫描与重新生成指纹。
