# 快速上手指南

只需三步，用最简单的方式开启你的第一次照片安全备份。

---

## 步骤 1：下载并打开桌面端

1. 前往 [PicHarbor Desktop 最新发布页面](https://github.com/Cc-Cece/PicHarbor/releases/latest)；
2. 下载免安装便携版压缩包 `PicHarbor-Gui-win-x64-portable.zip`；
3. 将压缩包解压到你的常用工作盘（例如 `D:\Tools\PicHarbor`）；
4. 双击运行 `PicHarbor.Gui.exe`。

:::tip[提示]
若要备份 iPhone 照片，电脑上需要有 Apple 基础驱动支持。如果你的电脑已经安装过微软商店的 **Apple Devices (Apple 设备)** 应用或 **iTunes**，无需任何额外配置即可直接使用。
:::

---

## 步骤 2：选择照片存放位置

首次打开 PicHarbor 时，软件会弹窗邀请你创建或指定一个**“归档目录”**：

1. 点击“浏览”，选择一个剩余空间充裕的磁盘（例如移动硬盘 `E:\MyPhotoLibrary` 或本地 `D:\Photos`）；
2. 目录布局推荐保持默认的 **`年/月 (year-month)`** 结构（例如自动整理为 `2025/2025-05/IMG_0001.HEIC`）；
3. 点击“确定”，软件会自动在目标盘建立轻量级索引文件。

---

## 步骤 3：开始第一次备份

### 如果你使用的是 iPhone：
1. 用原装或优质数据线将 iPhone 连接到 Windows 电脑；
2. 手机亮屏解锁，在弹出的**“信任此电脑？”**提示中点击**“信任”**，并输入手机锁屏密码；
3. 在 PicHarbor 桌面左侧菜单点击“设备备份”，软件会自动识别出你的 iPhone 型号及照片总数；
4. 点击界面醒目的**“开始归档”**按钮。你可以在界面上看到实时的传输进度、写入速度与当前正在保存的照片。

### 如果你使用的是 Android 手机：
1. 确保手机与电脑连接在**同一个家庭 Wi-Fi 路由器**下；
2. 手机打开自带或推荐的文件管理器并开启“远程管理 / FTP 服务”；
3. 在电脑端输入手机屏幕上显示的 IP 地址与端口号；
4. 点击“测试连接”并开始同步，PicHarbor 会智能拉取新增的照片和视频。

---

## 备份完成后可以做什么？

* **在电脑上流畅浏览**：切换到“画廊”或“表格”视图，按拍摄日期、相机型号甚至文件尺寸快速筛选回忆；
* **查看实况与视频**：直接双击全屏预览，支持播放实况照片（Live Photo）的伴生动态；
* **拔掉数据线**：备份是增量进行的，下次再次连接时，PicHarbor 会自动跳过已经存好的照片，只备份新拍内容！
