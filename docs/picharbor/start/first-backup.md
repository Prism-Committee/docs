# 第一次完整备份实操

当你积累了数年、多达数万张的照片（数十到数百 GB）需要初次归档时，请按照本篇教程操作，确保整个过程稳定、快速且万无一失。

---

## 备份前的贴心检查

* [ ] **准备一根稳定可靠的数据线**：请尽量使用原装线或高品质 MFi 认证编织线。避免使用松动、接触不良的破损老旧线缆。
* [ ] **确保目标盘空间充足**：初次备份如果手机里有 200 GB 照片，建议目标磁盘预留至少 250 GB 以上可用空间。
* [ ] **关闭电脑休眠**：在长达数十分钟至数小时的大体量初次备份期间，建议在 Windows 设置中将“睡眠超时”临时设置为“从不”，避免电脑因闲置进入睡眠中断传输。

---

## 完整的初次备份流程

```mermaid
flowchart LR
    A["插上数据线\n解锁手机信任电脑"] --> B["桌面端识别\n解析相机相册"]
    B --> C["点击开始归档\n流式传输与实时哈希"]
    C --> D["原子更名落盘\n更新本地 SQLite 索引"]
    D --> E["生成健康报告\n画廊立即可见"]
```

### 1. 设备接入与握手
* 将 iPhone 连上电脑，屏幕会弹出“要信任此电脑吗？”，务必点击**“信任”**并输入数字锁屏密码。
* 打开 PicHarbor 桌面端，状态指示灯将从黄色变为绿色，并显示类似：
  > `已连接: iPhone 14 Pro Max (已发现 18,420 个媒体项)`

### 2. 规划存放格式
点击设置中的“目录布局”。默认推荐为 **`year-month`**：
* 备份完成后，物理磁盘上将呈现井井有条的文件夹结构：
  ```text
  D:\Photos\
  ├── 2024\
  │   ├── 2024-01\
  │   └── 2024-02\
  └── 2025\
      ├── 2025-01\
      └── 2025-02\
  ```

### 3. 点击“开始归档”
点击主界面中央醒目的绿色按钮。此时界面将展示详细的实时监控看板：
* **当前进度百分比** 与 **已处理数量 / 总量**；
* **瞬时写入速度**（USB 3.0 / Type-C 接口下通常可稳定在 35~80 MB/s）；
* **当前正在写入的文件名** 与缩略图。

### 4. 如果遇到意外中断（如碰到线缆）怎么办？
不用慌张！PicHarbor 拥有事务级断点保护：
* 正在传输中的那张照片因为是临时写入，会自动废弃，**绝不会留下残缺破损的坏图**；
* 重新插好数据线后，再次点击“继续”，软件会自动比对索引，瞬间跳过前面已经完成的几千张照片，直接从断点继续往下备份！
