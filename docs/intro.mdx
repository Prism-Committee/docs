## WebShopX

**WebShopX** 是面向 Paper、Purpur、Spigot 与 Folia 服务端的 Web 商城系统，包含官方商城、玩家市场、钱包、订单与发货、充值和管理后台。

**项目与下载：** [GitHub 源码](https://github.com/Cc-Cece/WebShopX) · [Modrinth](https://modrinth.com/plugin/webshopx) · [MineBBS](https://www.minebbs.com/resources/x-folia-webshopx.15688/)

## WebShopX-Payments

**WebShopX-Payments** 是 WebShopX 的独立支付扩展插件，用于接入具体支付渠道。

**项目与下载：** [GitHub](https://github.com/Prism-Committee/WebShopX-Payments) · [Modrinth](https://modrinth.com/plugin/wsxpay) · [MineBBS](https://www.minebbs.com/resources/x-folia-webshopx-payments-webshopx.16526/)
