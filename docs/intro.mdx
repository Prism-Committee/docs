# Prism-Committee 文档

这里是 Prism-Committee 项目的统一文档站。

## WebShopX

**WebShopX** 是面向 Paper、Purpur、Spigot 与 Folia 服务端的 Web 商城系统，包含官方商城、玩家市场、钱包、订单与发货、充值和管理后台。

> 项目链接/下载：[Github](https://github.com/Cc-Cece/WebShopX-Issues)、[Modrinth](https://modrinth.com/plugin/webshopx)、[minebbs](https://www.minebbs.com/resources/x-folia-webshopx.15688/)

- **第一次使用或部署**：[Get started](./category/webshopx-get-started)
- **购买、交易、钱包、背包与拍卖**：[Guides](./webshopx/guides/overview)
- **服务器配置、治理和运维**：[Administration](./category/webshopx-administration)
- **HTTP API / 插件集成**：[Development](./category/webshopx-development)
- **查命令、错误码和精确协议**：[Reference](./webshopx/reference/overview)

也可以先打开 [WebShopX Overview](./webshopx/overview) 查看完整阅读地图。

## WebShopX-Payments

**WebShopX-Payments** 是 WebShopX 的独立支付扩展插件，用于接入具体支付渠道。

> 项目链接/下载：[Github](https://github.com/Prism-Committee/WebShopX-Payments)、[Modrinth](https://modrinth.com/plugin/wsxpay)、[minebbs](https://www.minebbs.com/resources/x-folia-webshopx-payments-webshopx.16526/)

- [WebShopX-Payments 文档](./category/webshopx-payments)
- 开发第三方支付 Provider：[WebShopXPaymentApi](./webshopx/webshopx-payment-api)
