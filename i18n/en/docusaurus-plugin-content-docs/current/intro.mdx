# Prism-Committee Docs

This is the unified documentation site for Prism-Committee projects.

## WebShopX

WebShopX is a web-first shop system for Paper, Purpur, Spigot, and Folia servers. It combines the official shop, player market, wallets, orders and delivery, recharge, and administration.

Choose what you want to do rather than first choosing a role:

- **First use or deployment**: [Get started](./category/webshopx-get-started)
- **Shopping, market, wallet, inventory, and auctions**: [Guides](./webshopx/guides/overview)
- **Server configuration, governance, and operations**: [Administration](./category/webshopx-administration)
- **HTTP API and plugin integration**: [Development](./category/webshopx-development)
- **Exact commands, errors, and protocol behavior**: [Reference](./webshopx/reference/overview)

Or open [WebShopX Overview](./webshopx/overview) for the complete reading map.

## WebShopX-Payments

WebShopX-Payments is the optional standalone payment extension for WebShopX.

- [WebShopX-Payments documentation](./category/webshopx-payments)
- Third-party payment provider development: [WebShopXPaymentApi](./webshopx/webshopx-payment-api)

## Documentation model

1. **Get started** gets you to the first successful result.
2. **Guides** solve product tasks.
3. **Administration** covers server operations and troubleshooting.
4. **Development** covers integrations and APIs.
5. **Reference** provides precise lookup material without duplicating tutorials.

Beta or experimental features should not be assumed to exist or be enabled on every stable server.
