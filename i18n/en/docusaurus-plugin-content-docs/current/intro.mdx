# Prism-Committee Docs

This is the unified documentation site for Prism-Committee projects.

## WebShopX

WebShopX is a web-first shop system for Paper, Purpur, Spigot, and Folia servers. It combines the official shop, player market, wallets, orders and delivery, recharge, and administration.

Choose a path:

- **Start here**: [WebShopX Overview](./webshopx/overview)
- **Players**: [Player Guide](./category/player-guide)
- **Server administrators**: [Server Administrator](./category/server-admin)
- **Developers**: [Developer Docs](./category/webshopx-developer)
- **Reference**: [WebShopX Reference](./category/webshopx-reference)

## WebShopX-Payments

WebShopX-Payments is the optional standalone payment extension for WebShopX.

- [WebShopX-Payments documentation](./category/webshopx-payments)
- Third-party payment plugin developers: [WebShopXPaymentApi Integration Guide](./webshopx/webshopx-payment-api)

## Documentation Rules

1. Tutorials explain how to complete a task.
2. Configuration, commands, and API reference should follow the current WebShopX implementation.
3. Beta or experimental features should not be assumed to exist or be enabled on every stable server.
4. When behavior differs, verify the exact WebShopX version first.
